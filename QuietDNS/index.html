QuietDNS 技术支持

QuietDNS 是一款面向 iPhone、iPad 和 Mac 的本地 DNS 广告与追踪拦截工具。它使用 Apple Network Extension 在设备本地处理 DNS，不是提供远程节点的传统 VPN。

常见问题

Q：QuietDNS 是 VPN 吗？
A：系统会显示本地 VPN 配置，这是 Apple Packet Tunnel 的工作方式。QuietDNS 没有远程 VPN 服务器，不改变公网 IP，也不代理全部网络流量，只处理 DNS 查询。

Q：为什么开启后没有活动记录？
A：请确认“设置”中的“保留本地查询记录”已开启。macOS 或浏览器可能使用缓存、加密 DNS 或其他网络扩展。请暂时关闭 Shadowrocket、其他 VPN、DNS 代理和浏览器的安全 DNS 后再次测试。

Q：为什么同时开启 Shadowrocket 后 QuietDNS 记录变少？
A：多个网络扩展可能争用 DNS 路由。Shadowrocket 的 DIRECT 规则只表示连接不经过代理节点，DNS 仍可能由 Shadowrocket 处理。测试 QuietDNS 时建议一次只启用一个 DNS/VPN 网络扩展。

Q：为什么访问网页后仍然出现广告？
A：QuietDNS 进行的是域名级 DNS 拦截，不能隐藏已经加载的网页元素，也不能处理应用内硬编码的广告、第一方广告或未经过系统 DNS 的连接。请确认相关规则已启用并完成更新。

Q：如何添加自己的规则？
A：进入“规则”，选择“黑名单”或“白名单”可编辑本地域名；选择“远程规则”可浏览内置目录；选择“第三方规则”可添加 HTTPS 订阅、导入文件或粘贴规则文本。

Q：支持哪些规则格式？
A：支持 AdGuard DNS 规则、hosts、纯域名、Loon/Surge 的 DOMAIN 与 DOMAIN-SUFFIX，以及 YAML 域名列表。只有域名级规则会进入 DNS 索引。

Q：DNS 请求会发送到哪里？
A：未命中拦截规则的查询会发送到“设置”中选择的上游 DNS。可选项包括自动选择、AliDNS、DNSPod Public DNS+、Cloudflare 和 AdGuard DNS。QuietDNS 不会把查询发送到开发者自己的日志服务器。

Q：支持哪些系统？
A：iOS 15 及更高版本、iPadOS 15 及更高版本、macOS 11 及更高版本。

排查建议

  1. 关闭其他 VPN、代理、DNS 配置和浏览器安全 DNS。
  2. 确认 QuietDNS 的本地防护状态为“已开启”。
  3. 确认“保留本地查询记录”已开启。
  4. 更新或重新编译已启用的规则。
  5. 重新访问一个尚未缓存的域名，再查看“活动”。
